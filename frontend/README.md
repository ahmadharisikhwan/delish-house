# ⚛️ Delish House - Frontend (React.js)

Aplikasi antarmuka web modern untuk platform **Delish House (UMKM Kuliner Berbasis AI)** yang dibangun menggunakan **React.js** dan **Vite**.

## 🌟 Fitur Frontend React.js
- **Struktur Komponen Modular**: Dibagi menjadi `Navbar`, `Hero`, `ProblemSection`, `SolutionSection`, `FeaturesSection`, `AiToolsSection`, `MerchantCatalog`, `WorkflowSection`, `StatsSection`, `CtaBanner`, `Footer`, `RegisterModal`, `Toast`, dan `BackToTop`.
- **Interaktif AI Copywriter**: Menghasilkan deskripsi produk kuliner otomatis dengan berbagai pilihan *tone of voice* (Menggugah Selera, Gaul, Promo, Resep Warisan).
- **Interaktif AI Smart Recommendation**: Filter menu kuliner otomatis berdasarkan anggaran belanja, suasana rasa (pedas, kuah hangat, dsb), dan kota.
- **Katalog UMKM Terintegrasi**: Menampilkan data mitra kuliner langsung dari backend API & SQLite database dengan tombol chat WhatsApp langsung ke pedagang.
- **Form Kemitraan UMKM**: Modal pendaftaran yang terhubung langsung ke basis data backend.
- **Performa Cepat**: Didukung Vite untuk hot module replacement (HMR) kilat dan ukuran bundle teroptimasi.

## 💻 Menjalankan Frontend
```bash
# Masuk ke direktori frontend
cd frontend

# Jalankan development server
npm run dev
```

Frontend akan aktif di: `http://localhost:3000` (atau port yang ditentukan Vite).
