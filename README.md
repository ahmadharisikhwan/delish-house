## 💡 Latar Belakang & Masalah

Usaha Mikro, Kecil, dan Menengah (UMKM)—khususnya skala mikro di sektor makanan dan minuman—merupakan tulang punggung perekonomian yang menyerap mayoritas tenaga kerja Indonesia. Namun, pedagang mikro sering kali menghadapi berbagai hambatan dalam era digital:

1. 📢 **Promosi Terbatas** — Mayoritas pedagang masih mengandalkan promosi manual dari mulut ke mulut tanpa katalog digital yang menarik.
2. 📋 **Informasi Tidak Terstruktur** — Foto sajian, daftar menu, varian, dan transparansi harga belum tersaji secara rapi dan profesional.
3. 📍 **Sulit Ditemukan (*Discoverability*)** — Calon pelanggan di area sekitar sering kali kesulitan menemukan lapak kuliner terdekat.
4. ✍️ **Keterbatasan Literasi Digital Marketing** — Pedagang kesulitan merangkai kata promosi (*copywriting*) produk yang menggugah selera.
5. 💬 **Komunikasi Terpisah & Kompleks** — Saluran pemesanan sering tercecer di berbagai media tanpa alur transaksi yang ramah pedagang kecil.

---

## 🚀 Solusi: Delish House

**Delish House** hadir sebagai platform web ringan, modern, dan sangat mudah digunakan (*accessible*) untuk menjembatani pedagang mikro dengan pelanggan lokal, tanpa membebani pedagang dengan potongan komisi platform yang mencekik.

### 🌟 Fitur Unggulan

- **🏪 Profil Usaha & Katalog Interaktif**: Tampilan katalog visual dengan transisi interaktif foto sajian, deskripsi menu, dan daftar harga transparan.
- **🤖 AI Copywriter**: Fitur AI cerdas yang secara otomatis membuat deskripsi produk kuliner yang persuasif, menggugah selera, dan siap pakai untuk promosi.
- **🎯 AI Smart Culinary Recommendation**: Rekomendasi kuliner cerdas yang dipersonalisasi berdasarkan selera konsumen, anggaran (*budget*), dan lokasi terdekat.
- **🗺️ Peta Lokasi Interaktif (*Geolocation*)**: Integrasi peta geolokasi agar calon pembeli dapat menemukan rute ke lapak kuliner UMKM terdekat.
- **💬 Direct CS Chat**: Pembeli dapat langsung terhubung dengan WhatsApp/kontak pedagang tanpa perantara pihak ketiga, menjaga margin laba 100% untuk pedagang.
- **📝 Form Pendaftaran Kemitraan & Interaksi Real-Time**: Alur onboarding mitra UMKM yang simpel dan cepat dengan notifikasi toast konfirmasi otomatis.
- **📈 Statistik & Counter Animasi**: Tampilan dampak dan pencapaian platform dengan animasi interaktif saat di-scroll.

## 🛠️ Arsitektur & Teknologi

Delish House dibangun dengan standar *modern web performance* untuk memastikan akses yang sangat cepat bahkan pada jaringan seluler berkecepatan rendah:

- **HTML5 Semantic**: Struktur semantik yang ramah mesin pencari (SEO) dan aksesibilitas ramah pengguna.
- **Vanilla CSS3 (Custom Design System)**:
  - Skema warna kurasi modern (*Warm Orange* `#FF6B00`, *Modern Blue*, *Slate Gray*).
  - Variabel CSS, Glassmorphism, Responsive Grid & Flexbox layout.
  - Tipografi Google Font: **Plus Jakarta Sans**.
  - Font Awesome 6 icon library.
- **Vanilla JavaScript (ES6+)**:
  - `IntersectionObserver` API untuk animasi counter statistik performan tinggi.
  - Sticky dynamic navbar dan smooth scrolling link tracker.
  - Modal onboarding interaktif dengan manajemen state dan event listener keyboard/escape.
  - Toast notification engine tanpa dependensi eksternal.
- **Asset Optimization**:
  - Seluruh aset gambar dikonversi dan dikompresi ke format **WebP** generasi modern (menghemat hingga 91% ukuran berkas).
- **SEO & Social Sharing Ready**:
  - Meta tag lengkap (Open Graph, Twitter Cards, robots.txt, sitemap.xml).
  - Schema Markup (JSON-LD) terstruktur untuk visibilitas mesin pencari Google.
- **Deployment**: Vercel Cloud Platform dengan sertifikat SSL/TLS otomatis dan distribusi CDN global.
=======
Platform web modern yang memberdayakan pelaku usaha mikro, kecil, dan menengah (UMKM) kuliner di Indonesia melalui integrasi kecerdasan buatan (*Artificial Intelligence*), etalase kuliner interaktif, dan komunikasi instan tanpa potongan komisi.

Proyek ini telah direstrukturisasi secara profesional menjadi arsitektur modular terpisah: **Frontend (React.js)**, **Backend (Node.js & Express)**, dan **Database (SQLite)**.

## 💻 Menjalankan Secara Lokal (Local Development)

Proyek ini tidak memerlukan instalasi runtime atau build step yang rumit. Anda dapat menjalankannya langsung di browser:

### Opsi 1: Buka Langsung di Peramban
1. Unduh atau clone repositori ini:
   ```bash
   git clone https://github.com/smartonesda/delish-house.git
   ```
2. Masuk ke direktori:
   ```bash
   cd delish-house
   ```
3. Buka berkas `index.html` dengan klik dua kali atau seret ke browser favorit Anda (Google Chrome, Microsoft Edge, Mozilla Firefox, dll).

### Opsi 2: Menggunakan Live Server (Visual Studio Code)
1. Buka folder proyek di VS Code:
   ```bash
   code .
   ```
2. Pastikan ekstensi **Live Server** (oleh Ritwick Dey) sudah terpasang.
3. Klik kanan pada berkas `index.html` lalu pilih **"Open with Live Server"**.
4. Website akan terbuka otomatis di alamat `http://127.0.0.1:5500/`.

### Opsi 3: Menggunakan Python HTTP Server
Jika Anda memiliki Python terpasang di komputer:
```bash
# Python 3
python -m http.server 3000
```
Buka browser dan navigasikan ke `http://localhost:3000`.

## ⚡ Panduan Menjalankan Aplikasi

Pastikan **Node.js** (v18+) dan **npm** sudah terpasang di komputer Anda.

### 1. Inisialisasi Basis Data (Opsional / Reset Data)
Basis data SQLite sudah disiapkan dengan data kuliner lokal. Jika ingin mereset atau mengisi ulang:
```bash
node database/init.js
```

---

### 2. Menjalankan Backend (Port 5000)
Buka terminal:
```bash
cd backend
npm run dev
```
Backend API aktif di: **`http://localhost:5000`**
- Health Check: `http://localhost:5000/api/health`
- Katalog UMKM: `http://localhost:5000/api/merchants`
- Statistik: `http://localhost:5000/api/stats`

---

### 3. Menjalankan Frontend React.js (Port 3000)
Buka terminal baru:
```bash
cd frontend
npm run dev
```
Buka peramban (*browser*) Anda di: **`http://localhost:3000`**
